# Papers

Reference literature and related research papers for this project.

## Key Research Areas

- **Vulnerability Detection with Deep Learning** — Neural approaches to finding software bugs
- **Code Property Graphs (CPG)** — Joern, combined AST+CFG+PDG representations
- **Graph Neural Networks for Code** — Devign, ReVeal, FUNDED, IVDetect
- **Taint Analysis** — Static data-flow tracking for security
- **Explainable AI (XAI)** — GNNExplainer, SubGraphX, Integrated Gradients, SHAP
- **Code Embeddings** — CodeBERT, GraphCodeBERT, UniXcoder
